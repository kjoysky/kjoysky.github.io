Why it's built this way
  • Red is spent once. The Keller Williams red marks the status ribbon and the door, nothing else, so the eye lands where the news is.
  • Facts in a rule-lined strip so bed, bath, square footage and year read as one unit and line up with the price above them.
  • The copy sells the walk, not the house. Hyde Park buyers are buying the Square and the porch. Three sentences, no adjectives stacked three deep.
  • Templated on purpose. Swap the photo, price, address and four facts and the next listing's flyer is done in ten minutes.

The listing itself is a sample. The phone number and website in the footer are your public ones.

A cover frame for the weekly show clip.

Sized 4:5 for the feed, dark so it stands apart from the listing posts. The topic changes every Saturday; the frame doesn't, so a clip from The Did You Know Real Estate Show can be cut and posted the same afternoon it airs.

How I'd use it every week
  • Monday: pull the best 45 seconds from Saturday's show, drop it behind this frame, post to Reels and Facebook with a one-line hook.
  • Cross-promote your lending partners. When a partner is on the show, they get a co-branded version of this frame to post too, which doubles the reach for free.
  • Archive it. Every clip gets filed by topic so a "rates" clip can be re-shared the next time rates move.
